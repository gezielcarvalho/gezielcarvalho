# Charter

## Purpose

Present Geziel Carvalho's professional engineering profile, skills, languages, and selected work in a clear public GitHub entry point.

## Audience and success

Recruiters, collaborators, clients, and mentees should be able to understand the core stack, communication strengths, and a small curated set of reliable technical examples. Success is accuracy and clarity, not maximum repository count.

## Ownership

The repository owner controls public content. GitHub Issues and the personal portfolio Project track supporting documentation and showcase-readiness work.
