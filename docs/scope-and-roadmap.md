# Scope and roadmap

## Current scope

- Public professional introduction, stack summary, language proficiency, and visual skill indicators.
- Links to selected personal showcase repositories through GitHub and the portfolio hub.

## Out of scope

- Publishing personal contact data, client information, credentials, infrastructure details, or unreviewed project claims.
- Changing account settings, pinned repositories, social links, or public README copy through documentation-only work.

## Review points

Select only projects with a distinct capability story, current documentation, safe public material, and reviewable quality evidence. Use a separate approved issue for any public README or profile-content rewrite.
